# CIFAR-10 Image Classification Using Convolutional Neural Networks (CNN)

## 📌 Project Overview

This project implements a Convolutional Neural Network (CNN) using Python and TensorFlow/Keras to classify images from the CIFAR-10 dataset into 10 different categories.

The project demonstrates the complete deep learning workflow, including dataset preparation, neural network architecture design, model training, performance evaluation, and analysis of classification errors.

## 🎯 Objectives

- Understand the fundamentals of deep learning and convolutional neural networks.
- Build and train a CNN using TensorFlow/Keras.
- Classify images into 10 object categories.
- Evaluate performance using appropriate classification metrics.
- Visualize training accuracy, training loss, and classification errors.
- Investigate challenges such as overfitting and model generalization.

## 📂 Dataset

The project uses the publicly available CIFAR-10 dataset.

- **Total images:** 60,000
- **Training images:** 50,000 before creating the validation split
- **Test images:** 10,000
- **Image dimensions:** 32 × 32 pixels
- **Image format:** RGB color images
- **Number of classes:** 10

### Classes

1. Airplane
2. Automobile
3. Bird
4. Cat
5. Deer
6. Dog
7. Frog
8. Horse
9. Ship
10. Truck

**Dataset source:** [Official CIFAR-10 Dataset](https://www.cs.toronto.edu/~kriz/cifar.html)

The dataset is loaded directly using the Keras dataset API.

## 🧠 Model Architecture

The project uses a CNN architecture consisting of the following layers:

- Input layer for 32 × 32 RGB images
- Convolutional layers with ReLU activation
- Max-pooling layers for spatial dimension reduction
- Fully connected dense layer with 128 neurons
- Dropout regularization to help reduce overfitting
- Softmax output layer with 10 class probabilities

### Architecture Flow

```text
Input Image (32 × 32 × 3)
          |
          v
Convolutional Layer (32 filters)
          |
          v
Convolutional Layer (32 filters)
          |
          v
Max Pooling (2 × 2)
          |
          v
Convolutional Layer (64 filters)
          |
          v
Convolutional Layer (64 filters)
          |
          v
Max Pooling (2 × 2)
          |
          v
Flatten Layer
          |
          v
Dense Layer (128 neurons, ReLU)
          |
          v
Dropout (0.4)
          |
          v
Output Layer (10 neurons, Softmax)
          |
          v
Predicted Image Class
```

## 📊 Model Evaluation

The trained model is evaluated using the following metrics:

- **Accuracy:** Measures the proportion of correctly classified images.
- **Precision:** Measures the correctness of positive class predictions for each category.
- **Recall:** Measures how many actual examples of each category are correctly identified.
- **F1-score:** Combines precision and recall.
- **Loss:** Measures the model's prediction error.

A confusion matrix is used to examine which image categories are frequently misclassified.

## 🔍 Challenges and Future Improvements

Potential challenges in this project include:

- Overfitting when the model learns training examples too closely.
- Confusion between visually similar object categories.
- Training time and computational resource limitations.
- Difficulty generalizing to images with ambiguous visual features.

Potential improvements include:

- Applying data augmentation.
- Tuning learning rates, batch sizes, and dropout rates.
- Experimenting with deeper CNN architectures.
- Comparing the baseline CNN with regularized models.
- Evaluating alternative architectures such as ResNet.

These improvements should be validated experimentally before concluding that they improve performance.
